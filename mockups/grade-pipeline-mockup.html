The "Grade" Pipeline — Raw vs. Graded

Same five buildings, every time. The only thing that changes is whether the QuestDay Grade is applied. This is the difference between "looks free" and "looks like it cost money."

Layer 1 — SourceGrab free CC0 art (Kenney & friends). Mismatched, plain, generic.
➞
Layer 2 — Grade ★ the moatOne consistent treatment stamps every asset: re-color, light, shadow, atmosphere.
➞
Layer 3 — RenderYour existing map + town views show the finished, cohesive world.

What this proves

  • The assets are commodity; the Grade is the product. Plain free buildings + one consistent treatment = a world that reads as a polished paid app.
  • One treatment, every asset. Pick a direction below and it stamps the map, every building, and every future biome the same way — that's what keeps it cohesive as the app grows.
  • It runs offline, once, at build time. The graded art ships as plain image files — zero new app dependencies, fully commercial-safe to ship in the installer.

Honesty note: these five buildings are stand-ins I drew in Kenney's flat style, deliberately plain so the Grade's effect is obvious. The real build grades Kenney's actual CC0 building PNGs the same way. The "raw" row is what dropping a free pack in with no treatment looks like.
